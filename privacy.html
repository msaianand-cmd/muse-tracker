Muse Tracker - Privacy Policy

Last updated: October 23, 2026

Overview

Muse Tracker is a personal, single-user application. It exists so that one individual - its developer and account holder - can read his own WHOOP data for personal step-goal tracking (a 10,000 steps daily goal). It has no other users, is not offered as a service, and is not commercial.

What data is accessed

With the account holder's explicit OAuth authorization, the application reads from the WHOOP API, for that account only: cycle data, including the daily step count (step_count) and day strain. Access is read-only. The application never writes to, modifies, or deletes anything in the WHOOP account.

How the data is used and stored

Step counts are stored on the account holder's own private home server and used only to report daily progress against his personal step goal. OAuth tokens are stored in a private credential vault on that server.

Sharing

None. Data is never sold, shared, transmitted to third parties, or used for advertising, analytics, or model training. The only systems that touch the data are the WHOOP API and the account holder's own server.

Retention and deletion

Data is retained on the account holder's server until he deletes it. Deleting it removes it permanently.

Revoking access

Authorization can be revoked at any time in the WHOOP app under Settings > Connected Apps. Revoking stops all further access immediately.
